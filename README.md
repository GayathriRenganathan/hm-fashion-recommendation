# H&M Fashion Recommendation System

## Overview

This project develops a personalized fashion recommendation system using the H&M Personalized Fashion Recommendations dataset from Kaggle.

The objective is to recommend relevant fashion articles to customers based on their historical purchase behavior and item characteristics.

The system follows a **two-stage recommendation architecture**:

1. **Candidate Retrieval:** Generates a pool of potentially relevant articles using multiple recommendation strategies.
2. **Learning-to-Rank:** Ranks the retrieved candidates using a LightGBM ranking model to produce the final personalized recommendations.

## Architecture

### Stage 1: Candidate Retrieval

Multiple retrieval strategies are combined to generate candidate articles for each customer.

The implemented strategies include:

- **Previous Purchases:** Retrieves articles previously purchased by the customer.
- **Item Similarity:** Identifies articles similar to items in the customer's purchase history.
- **Recency-Based Recommendations:** Uses recent purchase behavior to generate candidates.
- **ALS (Alternating Least Squares):** Uses collaborative filtering to identify potentially relevant articles.
- **Style Alternatives:** Retrieves articles sharing product and color characteristics with previously purchased items.

The retrieved candidates are combined and used as input to the ranking stage.

### Stage 2: Learning-to-Rank

A LightGBM ranking model is trained to predict the relevance of candidate articles for each customer. The LightGBM ranking model uses multiple feature groups to estimate the relevance of candidate articles for each customer.

**Article Metadata**
- Product type, graphical appearance, colour group, perceived colour value, department, and index group.

**Historical Popularity**
- Article purchase popularity calculated over 1-week, 2-week, 4-week, and 8-week historical windows.

**Customer Profile and Activity**
- Customer age, club membership status, fashion news frequency, total historical purchases, and last purchase week.

**User–Article Affinity**
- Previous purchase of the same article, historical department purchase count, and product-type purchase count.

**Candidate Retrieval Metadata**
- Source indicator identifying whether a candidate was generated by ALS, previous purchases, item similarity, recency, style alternative, or recency popularity.

The ranking model produces a personalized ordering of candidate articles, from which the top 12 recommendations are selected.

## Evaluation

The recommendation system is evaluated using a temporal validation strategy based on historical customer transactions. Evaluation is performed at both the candidate retrieval and ranking stages.

### Candidate Retrieval Evaluation

- **Candidate Recall@K:** Measures the proportion of actual purchased articles successfully retrieved by the candidate generation strategies. This evaluates how effectively the retrieval stage identifies potentially relevant articles before ranking.

### Ranking Evaluation

The final recommendations are evaluated using the following metrics:

- **Mean Average Precision (MAP@12):** Evaluates the precision of relevant recommendations across the ranked list.
- **Hit Rate@12:** Measures the proportion of customers who receive at least one relevant recommendation.
- **Normalized Discounted Cumulative Gain (NDCG@12):** Evaluates ranking quality while assigning greater importance to relevant articles appearing at higher positions.
- **Recall@12:** Measures the proportion of actual purchased articles included in the top-K recommendations.

These metrics provide complementary perspectives on retrieval coverage, recommendation relevance, and ranking quality.

## Dataset

The project uses the [H&M Personalized Fashion Recommendations dataset](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data) available on Kaggle.

The dataset contains customer information, article metadata, and historical transaction records.

Due to the huge dataset size, the raw dataset is not included in this repository. Download the dataset from Kaggle and place the files under`input/raw`.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/GayathriRenganathan/hm-fashion-recommendation.git
cd hm-fashion-recommendation
```

2. Create and activate a Python environment.

```bash
python3 -m venv venv
```
Python environment activation in different OS

   - **Windows (command prompt):**
   ```bash
   venv\Scripts\activate
   ``` 
   - **Windows (PowerShell):**
   ```bash
   .\venv\Scripts\Activate.ps1
   ```
   - **Windows (PowerShell):**
   ```bash
   source venv/bin/activate
   ```

3. Install the dependencies:

```bash
pip install -r requirements.txt
```

4. Download the H&M dataset from Kaggle and place the files under `input/raw/`.

5. Run the notebooks in the following order:

   - `data_cleaning.ipynb` – preprocesses the raw dataset.
   - `candidate_experiments.ipynb` – explores and evaluates candidate retrieval strategies.
   - `hm_recommendation.ipynb` – executes the final candidate retrieval and ranking pipeline.
